**FENRIX CRE GAME — gameplay overview** 🏢📊

The one-liner: *use predictive models to underwrite properties, compete for
acquisitions, manage the portfolio, and finish with the highest fund value.*

Attached is a 2–3 minute overview of the game we're building for Professor
Frenzel's CRE courses:

- **Before class** — teams get the dataset and build their model(s) at home
- **In class (~60–75 min)** — market updates → underwrite → sealed-bid auctions →
  operate your buildings (rent, vacancy, maintenance, surprises) → portfolio
  update → leaderboard; today's build runs a practice round plus four scored
  rounds, and the round count is configuration if you want about five
- **Model ladder** — valuation (all courses) + vacancy + rent/income (310);
  605 runs the simple version, 220 the Excel-friendly rollover — all from the
  same engine, tuned by configuration
- **Win condition** — highest portfolio NAV, with a separate board scoring
  model quality so the debrief can separate skill from luck

The build status section is honest: what's working today vs. planned this
cycle vs. optional later.
